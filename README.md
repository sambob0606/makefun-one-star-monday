A Python program that writes one original one-star review of Monday, written as if Monday were a restaurant, for [One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61) on make.fun.

The line:

> One star. Seated by the bathroom, cold coffee, and the waiter billed us for bread we never ordered. Never returning to Monday.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`.
